# Веб-сайт кафе «Вкус Востока» (XAMPP + PHP + SQLite)

Учебный проект по развёртыванию локального веб-сервера, работе с базой данных SQLite через PDO и контролю версий в Git.

## Структура проекта
- `index.html` — главная страница.
- `catalog.html` — каталог полуфабрикатов.
- `contacts.html` — страница контактов с формой обратной связи (метод POST).
- `style.css` — таблица стилей оформления.
- `diagnostic.php` — диагностика PHP и проверка драйвера `PDO_SQLITE`.
- `db.php` — подключение к локальной базе SQLite и автоматическое создание таблицы `feedback`.
- `process.php` — серверная валидация данных и запись в БД.
- `messages.php` — просмотр сохранённых обращений с сортировкой новых записей сверху.

## Требования и запуск
1. Установить **XAMPP** (требуются модули **Apache** и **PHP** с активным расширением `pdo_sqlite` в `php.ini`).
2. Разместить папку проекта в `C:\xampp\htdocs\vkus-vostoka`.
3. Запустить Apache в XAMPP Control Panel и открыть `http://localhost/vkus-vostoka/`.
4. Локальная база данных создаётся автоматически по пути `C:/xampp/site-data/vkus_vostoka.sqlite` (вне каталога `htdocs` для защиты данных). При переносе на другой ПК путь можно изменить в файле `db.php`.

## Проверка работы формы
1. Перейти на вкладку **Контакты** (`contacts.html`), заполнить поля и отправить форму.
2. После валидации и записи в SQLite произойдёт перенаправление на `messages.php?saved=1`, где отобразится новая запись.
